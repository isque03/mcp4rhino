# arch-documentation-sheets
## Steps
1. `create_section` / `create_elevation` / `create_detail_view`.
2. `create_dimension`, `create_room_tag`, `create_door_tag`, `create_window_tag`.
3. `create_schedule` for door/window/room.
4. `create_sheet` + `place_view_on_sheet`.
5. `export_images` / `export_pdf` (PNG fallback on Mac) / `export_dwg`.
